# Offline Android archive compatibility

Continue HaloLinux Android synchronization without changing the Android repository,
network listeners, runtime contracts, or existing Linux databases. The previous
interrupted work is not available in this workspace; this is a newly verified,
self-contained implementation, not a claim to recover its uncommitted files.

## Approach

Implement a read-only repository CLI, `python3 -B scripts/halo_brain_archive.py`,
matching Android's current schema-2 archive and version-1 encrypted envelope.
Use Python's ZIP/JSON/hash support and the distro cryptography package for AES-GCM.
This stage deliberately does not add a Python subprocess to the JVM daemon.
The alternative native JVM integration needs the complete build environment;
live peer transport additionally needs pairing, authorization and conflict rules.
Neither is implied by successful archive inspection.

## Constraints

- No extraction, database opening, user-record import, provider calls or networking.
- Do not accept passwords in arguments/environment; use a hidden prompt or stdin.
- Authenticate the entire encrypted stream before parsing its ZIP content.
- Bound input, KDF work, central directory, entries, expansion, JSON and record size.
- Refuse unsupported schema, ambiguous paths, duplicate entries/JSON keys, malformed
  ZIP layouts, checksum gaps, invalid completion and inconsistent section counts.
- Output only fixed-format inventory metadata, never record text or source filenames.
- Temporary snapshots are private and deleted on both success and failure. Disk
  contents are not guaranteed securely erased; Python cannot promise key zeroization.
- Inspection verifies container integrity and record syntax, not trust in the
  producer, record semantics, safe restoration, or Linux import compatibility.

## Evidence

Tests must include all three export profiles, corruption, hostile archive fixtures,
resource-limit boundaries, CLI secret handling and source immutability. Verify an
AES-GCM fixture generated by the exact Android BrainArchiveCrypto Kotlin source on
JDK21. Distinguish those wire-format fixtures from exports of a real Android app.
