# Standalone Brain API Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans; execute inline with tests.

**Goal:** A read-only local API for imported Android data, ready for later Halo wiring.
**Architecture:** Shared import-store opening and DTO parsing; a bounded reader;
a local Unix HTTP transport; a client and machine-readable contract.
**Tech Stack:** Python 3.11+, SQLite, Linux AF_UNIX/SO_PEERCRED; no new dependencies.
**Spec:** ../specs/2026-10-23-brain-api-design.md

## Global constraints

No Android/JVM edits, LAN listeners, CI, schema changes, auto-recovery or data writes.
Use the existing 052 import-store schema. Only configured source labels are served.
Raw inspection requires explicit startup/per-request opt-in. Fail closed on unsafe
memory history, unsupported semantics, stale cursors and exhausted query budgets.

## Review focus

Revocation retained by keep-local; source-scope leaks; stale paging; corrupt/mismatched
record provenance; malformed/slow HTTP requests and cleanup of sockets not owned by us.
